# Анализ клиентской базы телеком-оператора: EDA, ABC-анализ и исследование оттока

Исследование клиентской базы мобильного оператора на основе датасета с платформы Kaggle.

Цель проекта — изучить структуру клиентской базы, выявить закономерности оттока, определить категории клиентов с наибольшим вкладом в платежи и сформировать сегменты, для которых могут быть полезны отдельные меры удержания.

## Бизнес-задача

Телеком-оператору необходимо понимать:

* какие категории клиентов чаще всего прекращают пользоваться услугами;
* какие группы формируют основную часть платежей;
* как связаны отток, ежемесячная плата и срок обслуживания;
* какие характеристики отличают оставшихся клиентов от ушедших;
* на какие сегменты стоит обратить внимание при разработке стратегии удержания.

## Данные

В датасете представлены сведения о 7 043 клиентах.

Данные включают:

* **личные характеристики** — пол, наличие партнёра и иждивенцев, признак пожилого клиента;
* **техническую возможность подключения** — наличие телефонной связи, нескольких линий и интернет-подключения;
* **подключённые услуги** — онлайн-безопасность, резервное копирование, защиту устройства, техническую поддержку, потоковое телевидение и фильмы;
* **период обслуживания** — срок пользования услугами в месяцах;
* **условия договора и оплаты** — тип договора, безбумажный биллинг, способ оплаты;
* **платежные показатели** — ежемесячная плата и общая сумма платежей за период обслуживания;
* **целевой признак** — отказался ли клиент от продолжения договора.

## ABC-анализ по общей сумме платежей

Для ABC-анализа использовалась переменная `TotalCharges` — общая сумма платежей клиента за весь период обслуживания.

Клиенты были отсортированы по убыванию общей суммы платежей. Затем для каждого клиента рассчитаны:

* доля в общей сумме платежей;
* накопленная доля платежей;
* ABC-категория.

Использованы следующие границы:

* **A** — первые 80% накопленной суммы платежей;
* **B** — следующие 15%, до 95%;
* **C** — оставшиеся 5%.

### Распределение ABC-групп

| Группа | Клиенты | Доля клиентской базы | Доля общей суммы платежей |
| ------ | ------: | -------------------: | ------------------------: |
| A      |   2 701 |               38,35% |                    79,99% |
| B      |   1 693 |               24,04% |                    15,01% |
| C      |   2 649 |               37,61% |                     5,00% |

Таким образом, группа A формирует около 80% общей суммы платежей и включает примерно 38% клиентской базы.

Важно: в рамках данного исследования речь идёт об общей сумме платежей или выручке, а не о прибыли. Для расчёта прибыли необходимы данные о затратах.

## Отток в разрезе ABC-групп

| Группа | Количество ушедших клиентов | Всего клиентов | Доля оттока |
| ------ | --------------------------: | -------------: | ----------: |
| A      |                         492 |          2 701 |      18,22% |
| B      |                         374 |          1 693 |      22,09% |
| C      |                       1 003 |          2 649 |      37,86% |

Наиболее высокая доля оттока наблюдается в группе C — 37,86%. В этой группе клиенты имеют небольшой накопленный вклад в общую сумму платежей, что может быть связано с коротким сроком обслуживания.

Группа A характеризуется меньшей долей оттока — 18,22%. Это может указывать на то, что значительная часть клиентов с высоким накопленным вкладом уже давно пользуется услугами оператора.

## Сегментация по ежемесячной плате и сроку обслуживания

Клиенты были разделены на три группы по размеру ежемесячной платы:

* `low_ARPU` — низкий уровень ежемесячной платы;
* `medium_ARPU` — средний уровень;
* `high_ARPU` — высокий уровень.

Также клиенты были разделены по сроку обслуживания:

* 0–6 месяцев;
* 6–12 месяцев;
* 12–24 месяца;
* 24–36 месяцев;
* 36–48 месяцев;
* 48–60 месяцев;
* более 60 месяцев.

### Основные наблюдения

* Наиболее высокий отток наблюдается среди клиентов с высокой ежемесячной платой в первые месяцы обслуживания.
* В группе `high_ARPU` отток в первые 6 месяцев составляет 77,2%.
* В группе `medium_ARPU` максимальный отток также приходится на первые 6 месяцев — 63,2%.
* В группе `low_ARPU` отток в первые 6 месяцев ниже и составляет 37,0%.
* С увеличением срока обслуживания доля оттока снижается во всех группах.
* Для клиентов с высокой ежемесячной платой снижение оттока происходит медленнее, чем для клиентов с низкой платой.

Это позволяет предположить, что первые месяцы обслуживания являются критическим периодом, особенно для клиентов с высокой стоимостью услуг.

## ABC-анализ по ежемесячной плате

Дополнительно клиенты были распределены по накопленной доле ежемесячных платежей:

* `A_monthly`;
* `B_monthly`;
* `C_monthly`.

Распределение получилось следующим:

| Группа    | Количество клиентов |
| --------- | ------------------: |
| A_monthly |               4 224 |
| B_monthly |               1 674 |
| C_monthly |               1 145 |

В отличие от ABC-анализа по `TotalCharges`, эта сегментация отражает текущий размер ежемесячного платежа, а не накопленный вклад клиента за весь период обслуживания.

### Сопоставление общей и ежемесячной платы

| ABC по общей сумме | A_monthly | B_monthly | C_monthly |
| ------------------ | --------: | --------: | --------: |
| A_total            |     2 480 |       221 |         0 |
| B_total            |       785 |       601 |       307 |
| C_total            |       959 |       852 |       838 |

Большинство клиентов группы A по общей сумме платежей также относятся к группе A по ежемесячной плате. Однако часть клиентов с высокой текущей ежемесячной платой ещё не успела накопить значительную общую сумму платежей и поэтому попадает в группу C по `TotalCharges`.

## Комбинированная сегментация

Чтобы учитывать не только абсолютный размер ежемесячной платы, но и срок обслуживания клиента, был рассчитан индекс расходов:

```python
spending_index = MonthlyCharges / средний MonthlyCharges для группы tenure
```

На основании индекса сформированы три категории:

* **Lower** — ежемесячная плата ниже среднего более чем на 20%;
* **Average** — плата находится в диапазоне ±20% от среднего;
* **Higher** — ежемесячная плата выше среднего более чем на 20%.

### Отток по категориям расходов

| Категория | Доля оттока | Количество клиентов |
| --------- | ----------: | ------------------: |
| Lower     |       12,3% |               2 227 |
| Average   |       19,0% |               1 819 |
| Higher    |       41,9% |               2 986 |

Клиенты, которые платят выше среднего для своего срока обслуживания, демонстрируют наиболее высокую долю оттока — 41,9%.

В сочетании с ABC-группами по общей сумме платежей:

| Категория расходов | A_total | B_total | C_total |
| ------------------ | ------: | ------: | ------: |
| Lower              |    6,5% |    4,7% |   17,7% |
| Average            |    9,0% |   16,8% |   36,8% |
| Higher             |   24,9% |   48,8% |   70,3% |

Наиболее высокая доля оттока наблюдается среди клиентов, которые:

* платят выше среднего для своего срока обслуживания;
* ещё не успели накопить значительную общую сумму платежей;
* относятся к группе C по `TotalCharges`.

Клиенты категории `Higher-C_total` составляют 30,9% общего числа ушедших клиентов.

При этом клиенты категории `Higher-A_total` также представляют важный сегмент: они имеют высокий текущий платеж и уже сформировали значительный накопленный вклад в платежи оператора.

## Портреты клиентов

Для поиска возможных закономерностей была отдельно рассмотрена группа `Higher` — клиенты, чья ежемесячная плата выше среднего для их срока обслуживания.

### Более стабильный портрет

В качестве условного стабильного сегмента выделены клиенты, которые:

* имеют партнёра или иждивенцев;
* используют годовой или двухлетний контракт;
* оплачивают услуги автоматически банковским переводом или кредитной картой.

Результаты по этой группе:

* всего клиентов — 1 371;
* доля клиентской базы — 19,47%;
* доля оттока — 5,1%;
* средний ежемесячный платёж — 67,06;
* доля группы A по общей сумме платежей — 66,0%;
* доля клиентов с расходами выше среднего — 32,2%;
* доля в общей сумме ежемесячных платежей — 20,16%.

### Менее стабильный портрет

В качестве условного нестабильного сегмента выделены клиенты, которые:

* не имеют партнёра;
* не имеют иждивенцев;
* используют помесячный контракт;
* оплачивают услуги электронными или почтовыми чеками.

Результаты по этой группе:

* всего клиентов — 1 689;
* доля клиентской базы — 23,98%;
* доля оттока — 49,3%;
* средний ежемесячный платёж — 63,79;
* доля клиентов с расходами выше среднего — 51,5%;
* доля группы C по общей сумме платежей — 68,9%;
* доля в общей сумме ежемесячных платежей — 23,62%;
* доля ежемесячных платежей, связанная с ушедшими клиентами этой группы, — 12,83% от общей суммы ежемесячных платежей.

Эти портреты описывают различия между сегментами, но не доказывают причинно-следственную связь. Например, наличие семьи, тип договора или способ оплаты могут быть связаны с другими характеристиками клиента.

## Основные выводы

1. Группа A по `TotalCharges` формирует около 80% общей суммы платежей и включает 38,35% клиентской базы.

2. Наиболее высокая доля оттока наблюдается в группе C по общей сумме платежей — 37,86%. Это может быть связано с тем, что клиенты данной группы ещё не успели накопить значительный вклад в платежи.

3. Клиенты с ежемесячной платой выше среднего для своего срока обслуживания уходят чаще остальных: доля оттока в категории `Higher` составляет 41,9%.

4. Особенно высокий риск оттока наблюдается среди клиентов с высокой ежемесячной платой и небольшим сроком обслуживания. В первые 6 месяцев доля оттока в группе `high_ARPU` составляет 77,2%.

5. Помесячный контракт и отсутствие автоматической оплаты связаны с более высокой долей оттока. В нестабильном портрете, включающем эти признаки, доля оттока составляет 49,3%.

6. Наличие партнёра или иждивенцев, более длительный контракт и автоматическая оплата чаще встречаются в сегменте с низкой долей оттока. В выделенной группе таких клиентов доля оттока составляет 5,1%.

7. Для оператора важны два направления работы:

   * удержание клиентов с высокой ежемесячной платой;
   * сокращение оттока среди новых клиентов, ещё не сформировавших значительный накопленный вклад.

На основании исследования можно сформировать следующие гипотезы для дальнейшей проверки:

Для проверки гипотез потребуются дополнительные исследования, например сравнение сегментов с учётом размера выборки, статистические тесты и, при необходимости, модель прогнозирования оттока.

## Ограничения исследования

* Датасет не содержит временной истории изменений поведения клиента.
* Нельзя точно определить момент возникновения риска оттока.
* `TotalCharges` отражает накопленные платежи, но не является полноценным LTV в классическом продуктовом смысле.
* В исследовании нет данных о себестоимости услуг, поэтому нельзя оценить прибыльность сегментов.
* Выявленные зависимости не доказывают причинность.
* Некоторые сегменты могут пересекаться и содержать клиентов с разными характеристиками.
